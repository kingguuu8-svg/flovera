# Legacy QEMU/VPS Route Archive

This directory keeps the older QEMU, Linux guest, VPS, terminal, verification, and round-planning material.

The files are preserved for historical comparison, but they are no longer the active product direction on this branch.

Legacy runtime files that used to live at the repository root are archived under
`runtime/`:

- `runtime/rootfs/`
- `runtime/vm/`
- `runtime/bridge/`
- `runtime/scripts/`
- `runtime/artifacts/`

Current active direction:

- Android-local Koog agent runtime
- persistent sessions
- scoped Android workspace
- WebView preview surface
- model provider configuration
- productization toward a releasable Android app
