## Launch Channel Notes

### GitHub

GitHub is the source of truth. README must be practical before social posts
drive traffic to it. The repo should answer "what is it, why useful, how do I
try/build it, what are the limits?"

### X / Threads

Best use: short build-in-public story and GIF. Lead with the weird/novel thing:
an Android-local agent workbench. Keep claims concrete.

Suggested style:

- First-person maker voice.
- One strong demo.
- Bullet capabilities.
- Link to GitHub.
- Ask for feedback on the narrow alpha boundary.

### Hacker News

Use `Show HN:` only when there is a public repo and something usable to show.
HN audiences punish press-release language. The post should be direct,
technical, and limitation-aware.

Suggested title:

> Show HN: Flovera, an Android-local workspace agent for building small demos

Opening comment should explain:

- why Android-local;
- what works today;
- what does not work yet;
- why it is open source;
- what feedback is useful.

Do not ask for upvotes or coordinate voting.

### Product Hunt

Product Hunt is more visual and product-oriented. It needs assets: icon,
screenshots/GIF, tagline, maker comment. Use only after GitHub README and demo
capture are strong.

Suggested tagline:

> A local Android workbench for AI-generated demos and artifacts.

### Reddit / Chinese Social

Reddit wants context and tradeoffs, not a polished ad. Chinese social can lean
more into the "手机里无缝生成/预览/修改" product intuition.

Suggested style:

- Explain the original itch.
- Show a concrete demo.
- Admit the alpha limits.
- Ask for use-case feedback rather than "please star."

## Messaging Guardrails

Do:

- Say Android-local.
- Say scoped workspace.
- Say demo workbench.
- Say WebView/local preview.
- Say bounded Python.
- Say alpha and limits.

Do not:

- Claim VPS replacement.
- Claim guaranteed background automation.
- Claim app store deployment or production hosting.
- Claim it can manage email/stocks/external services without integrations.
- Overuse "vibe coding" unless channel context expects it.

## Recommended Core Message

> Flovera turns an Android phone into a small local AI workspace: chat, files,
> generated HTML, Python, and WebView preview in one loop.

## Style Matrix

| Channel | Voice | Proof | CTA |
| --- | --- | --- | --- |
| GitHub | precise, practical | README, build, screenshots | try/build/star if useful |
| X/Threads | maker story | GIF + bullets | feedback |
| HN | technical, skeptical | repo + limits | critique |
| Product Hunt | concise product | gallery assets | try alpha |
| Chinese social | product intuition | phone-native loop | discuss use cases |
