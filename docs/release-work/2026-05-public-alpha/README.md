# Flovera Public Alpha Research Workspace

This is an internal release-research workspace. It is not part of the public
Markdown allowlist and should not be pushed publicly unless the repository rules
are changed.

Required outputs for this pass:

- `promotion-skills-research.md`: GitHub skill research and reusable launch
  workflow references.
- `github-showcase-research.md`: GitHub README/showcase page research.
- `social-media-research.md`: open-source social launch research and style
  decisions.
- `github-showcase-draft.md`: draft GitHub showcase README copy, not yet applied
  to the public README.
- `social-copy-examples.md`: multi-angle social copy examples.

Working positioning:

Flovera is an Android-local workspace agent and demo workbench. It should be
marketed as a phone-native loop for creating, previewing, and iterating on small
local artifacts, not as a VPS replacement or guaranteed always-on automation
platform.
